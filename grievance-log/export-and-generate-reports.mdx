---
title: "Export grievance data and generate reports"
description: "Download grievance data as CSV or generate PDF report documents from the grievance list."
---

CareResolve provides two download workflows in the grievance list:

| Workflow | Output | Scope |
| --- | --- | --- |
| **Export data** | CSV | Grievances matching the export filters, or selected grievances |
| **Generate report** | PDF | One or more selected grievances |

Both workflows respect your organization, role, and facility access. There is no separate Reports area or export history.

## Export matching grievances as CSV

1. Open a grievance list and set the facility scope, search, filters, and sort order you need.
2. Select **Export data** above the list.
3. Review the number of matching grievances and the export filters.
4. Select **Export data** to download the CSV.

The dialog starts with the current list context. You can adjust Facility, Date range, Completion, Status, Category, F-tag, Assignee, and Other filters before exporting. Scoped queues keep their queue scope.

## Export selected grievances as CSV

1. Select one or more grievance rows with the checkboxes.
2. Open **Actions** in the selection bar.
3. Select **Export _N_ as CSV**.

Only the selected grievances are included. Selection can span pages, and the current list sort order is preserved.

## Generate PDF report documents

1. Select one or more grievance rows.
2. Open **Actions** and select **Generate report for _N_…**.
3. Choose **Summary** or **Full internal report**.
4. Choose whether to **Include attachments**.
5. Select **Generate report**.

To generate a report for one grievance, open the grievance action menu and select **Generate report…**.

CareResolve prepares the report and starts the download automatically. A report without attachments downloads as PDF. When attachments are included, the download is a ZIP package containing the PDF, eligible clean attachments, and an attachment manifest. Flagged, failed, or unavailable attachment files are skipped.

## Save generated files securely

Generated CSV, PDF, and ZIP files are not retained in CareResolve for later retrieval. If you need the file again, repeat the export or report workflow from the grievance list.

Downloaded files may contain sensitive resident, reporter, and case information. Confirm the selected grievances, facility scope, filters, report type, and attachments before sharing, and save the file only in an approved location.
