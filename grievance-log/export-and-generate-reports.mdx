---
title: "Export grievance data and generate reports"
description: "Download grievance data as CSV or generate full-detail PDF reports from the grievance list."
---

CareResolve provides two download formats from the grievance list:

| Format | Output | Scope |
| --- | --- | --- |
| **Spreadsheet (CSV)** | One row per grievance | Grievances matching the export filters, or selected grievances |
| **Full report (PDF)** | Full detail, each grievance starting on a new page | One or more selected grievances |

Both respect your organization, role, and facility access. There is no separate Reports area or export history.

## Export matching grievances as CSV

1. Open a grievance list and set the facility scope, search, filters, and sort order you need.
2. Select **Export data** above the list.
3. Review the number of matching grievances and the export filters.
4. Select **Export data** to download the CSV.

The dialog starts with the current list context. You can adjust Facility, Date range, Completion, Status, Category, F-tag, Assignee, and Other filters before exporting. Scoped queues keep their queue scope.

## Export selected grievances

1. Select one or more grievance rows with the checkboxes.
2. Select **Export _N_** above the list.
3. Choose **Spreadsheet (CSV)** or **Full report (PDF)**.
4. For a PDF, choose whether to **Include attachments**.
5. Select **Export**.

Only the selected grievances are included. Selection can span pages, and the current list sort order is preserved. PDF reports are limited in how many grievances they can include at once; the dialog tells you when to select fewer.

## Generate a report for one grievance

Open the grievance, open the three-dot action menu in the header, and select **Generate report…**. Choose whether to **Include attachments**, then select **Generate report**.

There is one PDF report: the full-detail record of the grievance. CareResolve prepares it and starts the download automatically. A report without attachments downloads as PDF. When attachments are included, the download is a ZIP package containing the PDF, eligible clean attachments, and an attachment manifest. Flagged, failed, or unavailable attachment files are skipped.

## Save generated files securely

Generated CSV, PDF, and ZIP files are not retained in CareResolve for later retrieval. If you need the file again, repeat the export or report workflow.

Downloaded files may contain sensitive resident, reporter, and case information. Confirm the selected grievances, facility scope, filters, format, and attachments before sharing, and save the file only in an approved location.
